## Overview

A modern, responsive business landing page built with **HTML**, **CSS**, and **JavaScript**. Designed for technology companies, startups, agencies, and digital businesses that want a polished online presence with strong visual hierarchy, easy navigation, and conversion-focused sections.

## Installation

1. Clone the repository

```bash
git clone https://github.com/utazifredrick/business-landing-page.git
```

2. Navigate into the project

```bash
cd business-landing-page
```

3. Open `index.html` in your browser

or use VS Code Live Server for a local preview.

## Usage

- Open the landing page in a browser to review the homepage layout.
- Use the navigation links to jump between sections.
- Test the contact form and newsletter subscription UI.
- Toggle dark/light mode with the theme button.

## Customization

You can customize this project easily by editing the source files.

- **Change colors**: update CSS variables and style rules in `css/style.css`
- **Replace logo**: edit the logo text in `index.html` or replace with an image
- **Update company information**: modify the text content across sections such as About, Contact, and Footer
- **Add portfolio projects**: duplicate and update project cards in the Portfolio section
- **Edit pricing plans**: change the pricing cards and plan details in the Pricing section
- **Update testimonials**: replace testimonial cards in the Testimonials section
- **Replace images**: swap placeholder images with real project or hero images
